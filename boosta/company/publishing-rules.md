# Publishing rules

1. Every public artifact requires explicit owner approval.
2. Sources and factual claims must be traceable.
3. Copyright, translation, image, audio, and territorial rights must be verified before release.
4. Personal or sensitive data must not enter public drafts unless deliberately approved.
5. Failed work is retained with an audit record; it is never silently discarded.
6. The system may prepare publication packages but may not make external API calls until a destination is configured and individually authorized.
