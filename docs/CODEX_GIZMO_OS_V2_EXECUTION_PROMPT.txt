PHASE-GATE LAW
No phase may start unless the previous phase has a valid machine-verifiable PASS checkpoint.

Every phase MUST define before execution:
- PRE-CHECK
- EXECUTE
- VERIFY
- ROLLBACK

Every phase MUST produce a runtime checkpoint JSON under `/srv/gizmo/checkpoints/` using the source-controlled checkpoint contract. Before starting the next phase, run:

node scripts/gizmo-checkpoint-gate.js /srv/gizmo/checkpoints/<previous-phase>.json

A non-zero exit blocks progression.

A phase checkpoint may be marked PASS only when:
- all mandatory verification checks pass,
- rollback readiness is confirmed,
- the recorded Git SHA matches the implemented source state,
- required human approval is APPROVED,
- no security control was weakened to make tests pass.

On verification failure:
1. STOP progression.
2. Record non-secret evidence.
3. Attempt only bounded repairs within current phase scope.
4. Re-run the complete mandatory verification suite.
5. If still failing, execute rollback.
6. Verify restoration to the prior PASS checkpoint.
7. Mark FAIL/ROLLED_BACK/BLOCKED as appropriate.
8. Do NOT start the next phase.
