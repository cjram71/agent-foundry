# Gizmo Skill Foundry

Skills are reusable tested procedures, not permanent personas.

Target shape:

```text
skills/<domain>/<skill-id>/
  SKILL.md
  manifest.json
  examples/
  tests/
  references/
```

A skill is not certified merely because files exist. Promotion requires sandbox execution, deterministic tests/evals, security review, versioning and the appropriate approval gate.

Initial domains:

- core
- research
- software
- business
- operations

Initial planned skills include mission-contract-builder, source-verification, competitor-analysis, business-process-scan, automation-opportunity-analysis, ROI analysis, workflow-contract-builder, project-bootstrap, feature-contract-builder, code-review, test-and-verify, dependency-review, security-review, incident-triage and post-mission-learning.
